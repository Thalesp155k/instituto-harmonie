Como publicar na Vercel:
1. Descompacte o ZIP.
2. Crie um repositório no GitHub e envie TODOS os arquivos da pasta.
3. Na Vercel, clique em Add New > Project.
4. Importe o repositório.
5. Framework Preset: Other.
6. Build Command: deixe vazio.
7. Output Directory: deixe vazio.
8. Clique em Deploy.

Também funciona arrastando a pasta para um serviço de hospedagem estática.
